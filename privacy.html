Privacy policy

Last updated: 16 November 2026.

Famiglia is a private assistant used by a single person, its owner. It is not offered to anyone else.

What data it uses

With the owner's permission, Famiglia reads and edits events in the owner's Google Calendar (scope calendar.events) to show free time and to add, change or remove the owner's own events and reminders. Events with other guests are created only after the owner explicitly approves each one.

Where data is stored

The access token is stored only on the owner's own computer. Calendar data is not sold, not shared with third parties and not used for advertising. Event details may be processed by the AI model the owner uses to run the assistant, only to answer the owner's own requests.

Google API Services User Data Policy

Famiglia's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions: open an issue at github.com/zamkofde-svg/famiglia-privacy.
